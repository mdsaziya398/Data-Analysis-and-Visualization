# 📊 Data Analysis & Visualization with Python

## 📌 Overview
This project focuses on exploring, cleaning, analyzing, and visualizing a dataset using Python libraries. It demonstrates basic data analysis techniques using Pandas and NumPy and data visualization using Matplotlib.

## 🎯 Objectives
- Load and explore datasets using Pandas.
- Perform numerical calculations using NumPy.
- Identify and handle missing values.
- Remove duplicate records.
- Perform statistical analysis.
- Group and analyze data.
- Visualize data using different charts.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## 📂 Dataset
The project uses the **Iris Flower Dataset**, which contains flower measurements and species information.

Dataset features include:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species

## 📈 Analysis Performed
- Display first and last records
- Dataset information and shape
- Statistical summary using `describe()`
- Missing value detection
- Duplicate removal
- Average sepal length calculation
- Minimum and maximum petal length
- Species distribution
- Group-wise average measurements

## 📊 Visualizations
- Bar chart – Average sepal length by species
- Line chart – Sepal length of the first 20 flowers
- Pie chart – Distribution of flower species

## 📚 Python Concepts Covered
- Data loading
- DataFrames
- Data cleaning
- Statistical operations
- GroupBy
- Data visualization
- NumPy calculations

## 🚀 How to Run
1. Clone this repository.
2. Install the required libraries:
   `pip install pandas numpy matplotlib`
3. Open the notebook using Jupyter Notebook or VS Code.
4. Run the cells sequentially.
